# Price sampling rules

`price-samples.json` feeds **Source A** of the price check (sampled second-hand listings).
These rules exist so the comparison is honest. Follow them exactly.

## Rule `R-newest-N`

1. For **each catalogue model** and **each platform** (Vinted, eBay, Depop, Facebook Marketplace),
   search the model name on the platform.
2. Sort by **newest** and record the **first N listings** (team default: N = 5 per platform),
   **regardless of price or condition**. Do not skip listings because they look cheap, expensive or odd.
3. For every entry record: `modelId`, `priceGBP` (asking price, excluding postage/fees), `condition`
   (`new_with_tags` | `like_new` | `good` | `worn`, mapped from the platform's own condition label),
   `platform`, `collectedOn` (ISO date) and `ruleId: "R-newest-N"`.
4. **No seller details**: no usernames, profile links, ratings, locations or listing photos.
5. Collect samples **before** choosing demo listings, so the demo cannot influence the sample.
6. **Never hand-remove entries.** Outliers are removed only by the code rule below.

Condition mapping: "New with tags" → `new_with_tags`; "New without tags" / "Very good" → `like_new`;
"Good" → `good`; "Satisfactory" / anything worse → `worn`.

## Outlier rule (code, `lib/priceSample.ts`)

Before computing statistics, exclude samples priced **above 3×** or **below ⅓** of the median of all samples
for that model (and condition, when restricted). Source A needs **n ≥ 5** samples after exclusion, otherwise it is
unavailable. Sampled-price confidence is capped at **0.7**.

Evidence wording: "Compared with 12 listings sampled on 10 Nov".

## Current file status

The committed `price-samples.json` is **placeholder data** generated by `scripts/placeholder-samples.ts`
(`ruleId: "SYNTHETIC-placeholder"`), so the pipeline runs end to end during development. While those rows are present,
every price evidence label says "(placeholder data, not real listings)" and `npm run seed` prints a warning.
Replace the file with real `R-newest-N` samples before any demo or before quoting numbers on a slide.
